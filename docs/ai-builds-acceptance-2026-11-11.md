默认模型为 DashScope **`qwen3.8-max`**，接口为 OpenAI Chat Completions。Node.js 24 的独立 worker 使用固定版本 1.5.2 的两个 Pi SDK。模型密钥加密落库，普通 API 返回掩码；Go Agent 不接收该密钥。

## 修复记录与边界

验收修复了三项真实问题：Qwen 未收到显式思考开关且不接受 `developer` 角色；源码请求等待缓存锁后授权可能失效；缓存回收后普通 Git 服务拒绝未公开的旧对象 ID。对应测试均观察到失败，再修复并通过。澄清提示也明确使用此前用户答案，避免重复提问。

完整私有证据和备份位于 `.local/artifactory-deploy/20261111-190200-ai/`；隔离源码、模型和缓存证据位于 `.local/ai-acceptance/`。这些目录含私有配置和备份，不能整目录公开。此前失败的模型额度、兼容性及缓存探针保留原始失败记录；最终结果使用修复后的独立运行。

本次真实宿主为 macOS arm64，使用 ad-hoc 签名；其余目标完成交叉编译。原生 Linux/Windows 服务生命周期沿用此前临时 CI 记录，本次没有宣称在这些宿主执行真实 AI 应用构建。未进行实体机重启、Developer ID/notarization，未发布 GitHub Release 或镜像。依赖仓库的离线镜像不在本期范围；旧源码对象在平台和上游均不可取得时，历史重试明确失败。
