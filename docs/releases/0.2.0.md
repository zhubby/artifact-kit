# Artifactory 0.2.0

发布日期：2026-11-14，Asia/Shanghai。

## 统一发布

- 根 `VERSION` 统一 Rust workspace、Node.js 包、lockfile 和两个 Helm Chart 的版本。
- CI 阻止版本漂移，Release 标签必须与统一版本完全一致。
- 发布控制平面、Web、Agent worker、Operator 和 Emissary 的 Linux amd64 / arm64 容器镜像。
- 发布带校验和的 Helm 包及源码提交标识。

## 本版能力

本版汇总已合入 main 的 Rust Emissary、Toasty 数据访问、持久化命令 / outbox 与控制平面多副本、独立 Source、对话式 AI 构建、用户自助注册、双语主题控制台及随 Web 发布的免登录 mdBook 文档。

新增受限内网试部署 profile：控制平面三副本、资源配额、命名空间内的部署身份和网络策略，默认不创建公网入口或集群级扩展。操作步骤见[统一版本与发布](../versioning.md)。

## 边界

- 核心 Chart 与 Operator Chart 的 Kubernetes 约束不同；Operator 需要 Kubernetes 1.34 或更高及其 CRD，不属于旧集群的核心服务试部署。
- 三个控制副本不代表单副本 PostgreSQL / S3 具备 HA。
- 镜像发布不等同于签名原生 Emissary / OTA 发布；后者仍需独立签名配置。
- 发布说明不是实际集群、真实 AI 模型、设备或物理平台的验收凭证，部署结果另行记录。
